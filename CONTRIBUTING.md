# Contributing to ldocs

Commit messages and pull-request titles follow the Conventional Commits format:

```text
type(optional-scope): short description
```

Allowed types:

- `build`
- `chore`
- `ci`
- `docs`
- `feat`
- `fix`
- `perf`
- `refactor`
- `revert`
- `style`
- `test`

Examples:

```text
feat(editor): add the pageless document surface
fix(storage): recover an interrupted checkpoint
docs: explain the local document bundle
```
